# Phantom Fish website

The company website of Phantom Fish, a neuroaesthetics lab. It is one static page (`index.html` and `styles.css`) with no build step, built from the Figma frame "Phantom Fish final" on the page "Final Websites" in "Phantom Fish – Phononaut – Websites".

## See it on your computer

Open `index.html` in a browser.

## Publish

The site can be published with GitHub Pages: in the repository's Settings, choose Pages, then "Deploy from a branch", branch `main`, folder `/ (root)`.
